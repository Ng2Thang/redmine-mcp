# Code of conduct

## Expected behavior

Be respectful, constructive, and considerate when discussing this project. Welcome contributors
with different backgrounds and experience. Focus feedback on the work, explain technical concerns,
and respect privacy. Disagreement is welcome when expressed without personal attacks.

Harassment, threats, discriminatory remarks, unwanted sexual attention, deliberate disruption,
and publishing another person's private information without consent are unacceptable.

These expectations apply to project discussions, code reviews, issues, and other project spaces,
including conduct while representing the project.

## Reporting

Report concerns to a repository maintainer through an established private contact channel.
If none is available, ask how to contact a maintainer privately without publishing the incident
details. There is no dedicated reporting address published here.

Include relevant context and links where safe. Do not post personal information publicly.
Maintainers should handle reports discreetly and share details only as needed to address them.
If a report involves a maintainer, contact another maintainer where one is available.

## Maintainer responses

Maintainers may request a correction, remove inappropriate content, issue a warning, or restrict
participation temporarily or permanently. Responses should reflect the severity, context, and
repetition of the conduct. Affected participants may ask for reconsideration through private
contact. Retaliation against someone making a good-faith report is unacceptable.
